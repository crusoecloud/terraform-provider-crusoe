# crusoe Provider

The Crusoe Cloud provider enables management of Crusoe Cloud resources.

## Example Usage

```terraform
terraform {
  required_providers {
    crusoe = {
      source = "crusoecloud/crusoe"
    }
  }
}

# Credentials come from ~/.crusoe/config or the CRUSOE_* environment variables.
# All attributes are optional.
provider "crusoe" {
  profile = "default"    # Profile in ~/.crusoe/config.
  project = "my-project" # Default project, as a name or UUID.
}

# A second configuration for resources in another project.
provider "crusoe" {
  alias   = "staging"
  project = "staging-project"
}
```

## Authentication

The provider reads credentials from the `~/.crusoe/config` file or from environment variables. Configure exactly one credential pair: an API key (`access_key_id` and `secret_key`) or a service account (`client_id` and `client_secret`).

The config file is TOML. Each section is a profile. The optional top-level `profile` key selects the profile to use when no other setting selects one.

```toml
profile = "production"

[default]
access_key_id   = "MY_ACCESS_KEY"
secret_key      = "MY_SECRET_KEY"
default_project = "my-project"

[production]
client_id       = "MY_CLIENT_ID"
client_secret   = "MY_CLIENT_SECRET"
default_project = "prod-project"
```

A profile can also set `api_endpoint`, and for service accounts, `token_url` and `audience`.

## Environment Variables

| Variable | Purpose |
|---|---|
| `CRUSOE_PROFILE` | Profile to load from `~/.crusoe/config`. |
| `CRUSOE_DEFAULT_PROJECT` | Default project, as a name or UUID. |
| `CRUSOE_API_ENDPOINT` | Crusoe API endpoint. |
| `CRUSOE_ACCESS_KEY_ID` | Access key ID of an API key. |
| `CRUSOE_SECRET_KEY` | Secret key of an API key. |
| `CRUSOE_CLIENT_ID` | Client ID of a service account. |
| `CRUSOE_CLIENT_SECRET` | Client secret of a service account. |
| `CRUSOE_TOKEN_URL` | OAuth2 token endpoint for a service account. Used only when the service account credentials come from the environment. |
| `CRUSOE_AUDIENCE` | OAuth2 audience for a service account. Used only when the service account credentials come from the environment. |

A complete credential pair in the environment takes precedence over the credentials in the profile. The provider never combines one field from the environment with one field from the profile. Set the token endpoint and the audience together. If only one of them has a non-default value, the provider fails with an error.

## Precedence

Each setting uses the first source that has a value, from highest to lowest.

**Profile:** `profile` in the provider block, `CRUSOE_PROFILE`, the top-level `profile` key in `~/.crusoe/config`, then `default`.

**API endpoint:** `api_endpoint` in the provider block, `CRUSOE_API_ENDPOINT`, `api_endpoint` in the selected profile, then `https://api.cloud.crusoe.ai/v1`.

**Project:** `project_id` on the resource or data source, `project` in the provider block, `CRUSOE_DEFAULT_PROJECT`, then `default_project` in the selected profile. If none of these is set and the user has exactly one project, the provider uses that project and shows a warning. If the user has more than one project, the provider fails and asks you to set one.
